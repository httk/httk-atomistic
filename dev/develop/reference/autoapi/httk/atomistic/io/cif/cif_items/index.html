httk.atomistic.io.cif.cif_items¶

The lossless CIF item model: data blocks as ordered, structured syntax.

A CIFBlock holds exactly what a CIF data block says, in written order: data items, loops, comments and save frames, with numbers kept as written (DecimalScalar). It knows nothing about structures. What is part of the model follows the content rule of CIFStructure.

class httk.atomistic.io.cif.cif_items.CIFBlock[source]¶

One CIF data block, losslessly: its items in written order and the comments around it.

Parameters:

  • name – The block name as written (after data_).

  • items – The block’s items in written order; the inline comment on the data_ line, if any, comes first.

  • header – The file’s header comment lines (the run of comment lines from line 1), carried by every block of the file so a block can be written alone.

  • leading – The own-line comments between the header (or the previous block) and the data_ line.

  • dialect – "cif" (CIF1, or full CIF2 when the header’s first line is the CIF2 magic code) or "mcif" (CIF1 plus lists, as the magnetic CIF reader reads it).

Raises:

ValueError – If a value, name or comment placement cannot be written in the block’s syntax, such as a table outside CIF2 or a list in CIF1.
