.. py:class:: StructureAPI

   Bases: :py:obj:`abc.ABC`


   Define the canonical structure interface.

   It declares the Unitcell quartet that every structure backend produces from its
   own native representation and every structure view builds its presentation
   from: ``cell``, ``sites``, ``species``, and ``species_at_sites``. This is the
   single interchange format; there is no pairwise conversion between backends.


   .. py:property:: cell
      :type: httk.atomistic.models.cell.cell.Cell

      :abstractmethod:


      Expose the structure's cell.


   .. py:property:: sites
      :type: httk.atomistic.models.sites.sites.Sites

      :abstractmethod:


      Expose the structure's site coordinates.


   .. py:property:: species
      :type: tuple[httk.atomistic.models.species.species.Species, ...]

      :abstractmethod:


      Expose the structure's distinct species.


   .. py:property:: species_at_sites
      :type: tuple[str, ...]

      :abstractmethod:


      Expose the species occupying each site.


   .. py:property:: charge
      :type: fractions.Fraction | None


      Expose the explicitly assigned net charge of the cell content.

      ``None`` means unstated and is never derived from the species; it is distinct
      from an explicit zero.

      :return: The assigned charge, or ``None`` when it is unstated.


   .. py:property:: bonds
      :type: BondNetwork | None


      Expose the bond network, or ``None`` when none is known (always, for a structure without one).

      See :class:`~httk.atomistic.BondNetwork`; on a unit-cell presentation its pairs and shapes
      index ``sites``.

      :return: The network, or ``None``.


   .. py:property:: site_moments
      :type: httk.atomistic.models.moments.backend.SiteMomentsBackend | None


      Expose optional per-site magnetic moments in ``sites`` order.

      ``None`` means "nothing stated", not "zero moments".

      :return: The site moments, or ``None`` when they are unstated.


   .. py:method:: cartesian_site_moments_floats()

      Return per-site Cartesian moments as float rows, or ``None``.

      ``None`` covers both unstated moments and a collinear representation, which has
      no Cartesian frame to present.

      :return: The Cartesian moments as float rows, or ``None``.



   .. py:method:: without_charges()

      Return an EXPLICIT lossy projection that drops declared oxidation states.

      The canonical structure components, the bond network and semantic metadata are
      preserved. A structure without species charges is returned by identity; charged
      structures are rebuilt in the canonical unit-cell family.

      :return: A charge-free structure, or this structure when already charge-free.



   .. py:method:: canonical_bare_protostructure()

      Return the canonical assigned-species classification of this structure.

      **Unlike every other canonical classification, this method identifies the two hands**:
      it behaves as ``preserve_chirality=False``, so a crystal and its mirror image get the
      same label, mirror descriptions are used and an enantiomorphic pair collapses to its
      lower-numbered member. Use the classification canonicalizers, whose default keeps the
      hand, to tell the hands apart. As for every label, the structure of species classes is
      classified.

      :return: A standalone canonical protostructure value; an undetermined one (see
          :func:`~httk.atomistic.canonical_bare_protostructure`) if its Wyckoff part does not finish
          within that function's default budget.
      :raises CanonicalizationLimitError: If :func:`~httk.atomistic.canonical_asu`, which runs
          first, exceeds its limit; it returns no undetermined value.



   .. py:method:: canonical_bare_prototype()

      Return the canonical anonymous geometrical classification of this structure.

      **Unlike every other canonical classification, this method identifies the two hands**:
      it behaves as ``preserve_chirality=False``, so a crystal and its mirror image get the
      same label, mirror descriptions are used and an enantiomorphic pair collapses to its
      lower-numbered member. Use the classification canonicalizers, whose default keeps the
      hand, to tell the hands apart. As for every label, the structure of species classes is
      classified.

      :return: A standalone canonical prototype value; an undetermined one (see
          :func:`~httk.atomistic.canonical_bare_prototype`) if its Wyckoff part does not finish
          within that function's default budget.
      :raises CanonicalizationLimitError: If :func:`~httk.atomistic.canonical_asu`, which runs
          first, exceeds its limit; it returns no undetermined value.

   .. py:method:: multiplicities()

      Return how many unit-cell sites each represented site contributes.

      The canonical structure interface presents a unit cell, so each row contributes
      once. Symmetry-reduced representations override this with their orbit counts.

      :return: One multiplicity per represented site.



   .. py:property:: implicit_atoms
      :type: tuple[str, ...]


      Expose species definitions whose atoms have no represented coordinates.

      :return: Unused species names in species-definition order.

      Expose composition-related features derived from canonical components.
