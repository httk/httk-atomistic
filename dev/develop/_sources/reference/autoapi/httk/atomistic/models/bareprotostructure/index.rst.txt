.. py:class:: WyckoffOccupation

   Store one Wyckoff orbit occupied by one possibly disordered species class.

   The species is stored as its class (see
   :mod:`httk.atomistic.models.species.classes`): its constituents, their exact
   concentrations and its attached atoms, named by the class name. The source name, original
   name, labels, charges, spins, mass and concentration precision are dropped, so species
   with equal chemistry form one class whatever they were called.

   :param wyckoff: The Wyckoff letter in the standard setting.
   :param species: The real species occupying the orbit.
   :raises ValueError: If the species contains the unknown symbol ``X`` or only ``vacancy``.


   .. py:attribute:: wyckoff
      :type:  str


   .. py:attribute:: species
      :type:  httk.atomistic.models.species.species.Species


.. py:class:: BareProtostructureAPI

   Bases: :py:obj:`abc.ABC`


   The common interface for standard-setting occupied Wyckoff positions.

   Composition and formula derivations from this interface use the standard-setting
   conventional-cell scale, independently of the setting or transform of a source
   structure from which a protostructure was recognized.


   .. py:property:: spacegroup
      :type: httk.atomistic.symmetry.spacegroup.Spacegroup

      :abstractmethod:


      Return the standard-setting space group.


   .. py:property:: occupations
      :type: tuple[httk.atomistic.models.protostructure.occupation.WyckoffOccupation, ...]

      :abstractmethod:


      Return the occupied Wyckoff positions in canonical order.


   .. py:property:: determined
      :type: bool


      Return whether every part of the label was determined.

      A canonicaliser that runs out of its time budget returns an undetermined value instead,
      which holds only its label, with ``X`` for the part that is not determined (see
      :meth:`~httk.atomistic.BareProtostructure.undetermined`). Its other parts raise
      ``ValueError`` when they are not known from the label.


   .. py:method:: multiplicities()

      Return tabulated standard-setting multiplicities for each occupation.

      These are deliberately not multiplicities from a source structure's transform;
      they define the provenance-independent conventional-cell scale of this value.

      :return: The standard-setting multiplicity for each occupation.



   .. py:property:: nsites_conventional
      :type: int


      Return the total number of sites in the standard conventional cell.

      :return: The conventional-cell site count.


   .. py:property:: formula
      :type: httk.atomistic.models.formula.formula_view.ChemicalFormulaView


      Return a reduced formula at the standard conventional-cell scale.

      :return: The conventional-cell reduced formula view.


   .. py:property:: anonymous_formula
      :type: httk.atomistic.models.formula.formulatype_view.FormulatypeView


      Return the Formulatype of the species-class site counts, the label prefix.

      Each species class counts its summed conventional multiplicity, whatever its
      occupancy; ``AnonymousFormulaView(self)`` gives the composition-based formula.

      :return: The site-count anonymous formula view.


   .. py:property:: label
      :type: httk.atomistic.models.bareprotostructure.label.BareProtostructureLabel


      Return the httk protostructure label of this protostructure.

      The label's unsuffixed part orders classes by
      :func:`~httk.atomistic.models.prototype.notation.class_order_key` (largest summed
      conventional multiplicity first, then sorted Wyckoff letters), so it is the prototype
      label of the erased anonymous prototype; the suffix lists the class species names.
      This is NOT an AFLOW label: AFLOW orders classes alphabetically by element (see
      :attr:`aflow_label`). Any faithful render is *the* protostructure label; the
      *canonical* protostructure label comes from a normalizer-canonical protostructure.

      :return: The protostructure label view.


   .. py:property:: aflow_label
      :type: str


      Return the AFLOW-style label of this protostructure.

      Unlike :attr:`label`, AFLOW orders classes alphabetically by element symbol and
      reassigns the anonymous symbols in that order, so the unsuffixed prefix depends on
      the chemistry. Provided for interoperability only.

      :return: The AFLOW-style label text.


   .. py:property:: bare_protostructure
      :type: Self


      Return this protostructure value.

.. py:class:: BareProtostructure(spacegroup, occupations)

   Bases: :py:obj:`httk.atomistic.models.bareprotostructure.backend.BareProtostructureBackend`


   Store only standard-setting Wyckoff occupations, without geometrical refinement.

   Occupations carry no cell: they are read in a right-handed basis of the standard setting,
   so in a Sohncke group they name one hand of the crystal.

   :param spacegroup: The standard-setting space group or its IT number.
   :param occupations: Occupied Wyckoff positions and their assigned species, each stored as
       its species class (see
       :class:`~httk.atomistic.models.protostructure.occupation.WyckoffOccupation`).


   .. py:attribute:: kind
      :type:  ClassVar[str]
      :value: 'bare_protostructure'



   .. py:method:: undetermined(label)
      :classmethod:


      Return the undetermined bare protostructure of a label in which ``X`` marks what is not determined.

      The canonicalisers return such a value when a part did not finish within its time budget; it
      holds only its label, ``<Formulatype>_X:<names>`` or
      ``<Formulatype>_<Pearson>_<number>_X:<names>``. Two undetermined values are equal when their
      labels are; that does not mean their structures are the same.

      :param label: The undetermined label.
      :return: The undetermined value, with ``determined`` false.
      :raises ValueError: If ``label`` is not an undetermined bare protostructure label.



   .. py:property:: spacegroup
      :type: httk.atomistic.symmetry.spacegroup.Spacegroup


      Return the standard-setting space group.

      :type: tuple[httk.atomistic.models.protostructure.occupation.WyckoffOccupation, ...]


      Return the canonical occupied Wyckoff positions.
